# ShporaMIREA — фронтенд

React 19 + TypeScript + Vite, стили на CSS Modules. Мобильная и десктопная раскладки (переход на 900px).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов и сборка
```

Адрес бэкенда задаётся в `.env.local` (шаблон — `.env.example`):

```
VITE_API_URL=http://localhost:8000
```

Бэкенд из корня репозитория: `docker compose up --build`.

## Структура

```
src/
├── api/          # http.ts — клиент бэкенда (токен, ошибки, все запросы), errors.ts
├── auth/         # AuthContext: пользователь, вход, регистрация, выход
├── components/   # PostCard, PostDialog (просмотр и скачивание файлов), FilterPanel/Sheet, Dropdown, ...
├── lib/          # хуки ленты, форматирование, токен, скачивание
├── pages/        # Лента, Профиль, Регистрация, Вход, форма поста, Модерация, Пользователи (админ)
└── config.ts     # название приложения, размер страницы, порог автобана
```

## Роли и страницы

| Страница | Кто видит |
|---|---|
| `/` лента, поиск, фильтры (институт, предмет, год, семестр, тип работы, преподаватель) | все |
| `/profile`, `/profile/edit`, `/profile/password` (смена пароля), `/posts/new`, `/posts/:id/edit` | студент и выше |
| `/moderation` — справочники (институты, предметы, семестры, типы работ, преподаватели) | модератор, администратор |
| `/admin` — пользователи: роли, бан, разбан, предупреждения | администратор |

Кнопки «Изменить» и «Удалить» появляются у собственных постов, кнопка со щитом (модерация поста: удаление
с отметкой «нарушает правила» и выдача предупреждения) у чужих постов для модераторов и администраторов.

Бэкенд не хранит оригинальные имена файлов, число страниц и размер: файлы называются «Файл 1.pdf».
